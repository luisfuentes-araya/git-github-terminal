# 04 - Trabajo diario con Git

## Cambiar archivos

Editas código normalmente en tu editor.

## Revisar cambios

```bash
git status
git diff
```

- `git status`: muestra el estado actual.
- `git diff`: muestra diferencias línea por línea.

## Guardar cambios

```bash
git add .
git commit -m "agrega nueva funcionalidad"
git push
```

Este es el ciclo normal para subir trabajo a GitHub.
