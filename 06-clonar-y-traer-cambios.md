# 06 - Clonar y traer cambios

## Clonar un repositorio

```bash
git clone https://github.com/usuario/repositorio.git
```

Descarga un repositorio completo desde GitHub.

## Traer cambios

```bash
git pull
```

Actualiza tu proyecto local con los últimos cambios del remoto.

## Enviar cambios

```bash
git push
```

Sube tus commits al repositorio remoto.
