# 05 - Ramas en Git

## Crear una rama

```bash
git branch nueva-rama
```

Crea una rama nueva.

## Cambiarse a una rama

```bash
git checkout nueva-rama
```

O también:

```bash
git switch nueva-rama
```

## Crear y cambiar al mismo tiempo

```bash
git checkout -b nueva-rama
```

## Ver ramas

```bash
git branch
```

## Fusionar ramas

```bash
git merge nueva-rama
```

Une los cambios de una rama con otra.
