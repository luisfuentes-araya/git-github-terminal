# 02 - Comandos iniciales de Git

## Iniciar un repositorio

```bash
git init
```

Crea un repositorio Git dentro de la carpeta actual.

## Ver estado

```bash
git status
```

Muestra qué archivos cambiaron, cuáles están listos para commit y cuáles no.

## Agregar archivos

```bash
git add .
```

Agrega todos los cambios al área de preparación.

```bash
git add archivo.txt
```

Agrega solo un archivo específico.

## Hacer commit

```bash
git commit -m "mensaje del cambio"
```

Guarda una versión del proyecto con un mensaje descriptivo.
