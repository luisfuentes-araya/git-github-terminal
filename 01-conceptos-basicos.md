# 01 - Conceptos básicos de Git

## ¿Qué es Git?

Git es un sistema de control de versiones. Sirve para guardar el historial de cambios de un proyecto y trabajar de forma ordenada.

## ¿Qué es GitHub?

GitHub es una plataforma donde puedes alojar repositorios Git en la nube.

## Conceptos clave

- **Repositorio**: carpeta de proyecto administrada por Git.
- **Commit**: punto de guardado del historial.
- **Branch**: rama de trabajo.
- **Remote**: repositorio remoto, por ejemplo en GitHub.
- **Origin**: nombre por defecto del remoto principal.

## Flujo básico

1. Creas un proyecto.
2. Inicializas Git.
3. Agregas archivos.
4. Haces commit.
5. Conectas con GitHub.
6. Subes cambios con push.
